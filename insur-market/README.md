# Insur Market

Insur Market is a standalone shopping protection concept app. It includes sample quotes, example plans, browser-saved demo plans, and a sample claim flow.

## Run locally

Requires Node.js 18 or newer. In this folder, run:

```sh
npm start
```

Open <http://127.0.0.1:3001>. Set `PORT` to use a different local port.

The demo saves plans and sample claims in this browser's local storage. It does not issue real insurance, accept payment, or file real claims. Sample coverage and prices are illustrative.
